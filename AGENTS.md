## Product lock

- Kit URL: `pitchkit.app/k/[handle]`. Public on first successful connect. Handle frozen by default; IG rename does not move our URL unless they opt in on reconnect (WHA-313: **Update kit URL to @{new}**; default = keep; old `/k/…` 404s; collision `-2`; keep `.` `_`). Missing/disconnected → 404.
- Instagram is login (Professional only — Business **or** Creator; Personal cannot power Insights; `/?error=personal` + PROFESSIONAL copy). Pitchkit session = httpOnly cookie (`pitchkit_session`). Continue GET/POST `/auth/instagram` is Instagram Business Login when `IG_APP_ID` + `IG_APP_SECRET` exist; otherwise stub seed `demo` (not an Instagram token; seed tokens stay null). When live secrets exist, `resolveSession` returns null for leftover seed `demo` so `/` shows Continue with Instagram and `/insights` goes home (public `/k/demo` stays). Failed OAuth finish clears `pitchkit_session`. `writeGraphSnapshot` tries SQL then KV `graph:` (never refuse KV solely because Hyperdrive is bound; thrown SQL → false → KV); false → no session cookie, `/?error=persist`. After a true write, set `pitchkit_session` to the in-memory handle on a single `Set-Cookie` — do not re-read via `resolveSession` (a second Set-Cookie on that 303 can fold on OpenNext/Workers and leave leftover `demo`). Landing OAuth errors: `oauth_state` / `oauth_exchange` / `oauth_me` / `personal` / `oauth_poll` / `persist`. If Insights poll fails after `/me`, persist a minimal snapshot (empty media/reach/audience) and still log in. If `resolveSession` succeeds, `GET /` redirects to `/insights`. `/insights` without the cookie → `/`. Sign out `/auth/sign-out` clears the cookie (kit stays public). Disconnect `POST /auth/disconnect` clears the cookie, stamps `disconnected_at` on the Graph snapshot, nulls tokens, and 404s the kit. Reconnect re-runs the same path (WHA-313 `update_handle=1` optional; default keep; no rename UI on the stub). Live finish never sets `pitchkit_session=demo` when `/me` username is not `demo` — a Graph snapshot stuck on handle `demo` escapes via unique-handle rules and is rewritten under that handle. `/k/[handle]` is public (no cookie).
