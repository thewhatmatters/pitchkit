# Pitchkit lights-on

Design + User Research. 2026-09-02. Not a layout lock.

Randy: Pitchkit stays free. This file is how we keep the lights on without breaking that. Bench SoT with `SWOT.md`, `GLOSSARY.md`, `PLAN.md`, `AGENTS.md`. Interviews unrun.

Security: do not sell the list or rates. Ads never on kit fields. No pixel that can see contact or rate on `/k/[handle]`.

## Free promise

`/k/[handle]` stays free, including Insights objects when connected (typical reach, saves, 30-day chart, geo / age / gender). Hide when missing. Dash, not zeros.

**Breaks the promise**

- Paywall the share link (Later: share kit = current paid Social).
- Gate reach / saves / demographics behind a paid plan.
- Watermark so hard a brand bounces.
- Sell contacts.
- Ads or pixels on contact or rate slots.

## Options that do not break free

1. **Freemium around the kit.** PDF export, custom domain, strip “via Pitchkit.” Brand still gets a free `/k/`. Closest to Beacons / CollabKit / mediakit.bio.
2. **Ads only off `/k/`.** Insights chrome or marketing. Never on the brand kit — a 30s hire page with ads looks cheap and fails the grid-check job.
3. **Marketplace take-rate later**, if we ever run deals. Not v1. Do not put rates on the kit (Randy skipped + Security: do not sell rates).

## Rec

Keep `/k/` fully free. Lights-on = optional PDF / custom domain first. Ads only off-kit if we need them sooner. Do not copy Later’s paid-to-share.
