## Two jobs

Not dashboards.

**Brand on `/k/[handle]` (~30s).** Spend or pass. Is the audience real (ER), how many people usually see a post (typical reach), are they in my market (geo / age / gender lists), proof posts, exact sourced bio. They verify against the public grid.

**Creator before share.** Will this survive that check. Last-updated, Insights connected, empty not zeros, no padded ER. Insights is how they connect — not a second kit.

## SWOT

Feature compare is evidence only. Spine:

### Strengths

- Honest kit a brand can check in ~30s.
- ER labeled: (likes + comments) ÷ followers. Same formula on every kit. Tooltip says so.
- Typical reach, saves, and the 30-day chart are surfaced. Later buries them.
- Posts ranked saves → reach → likes, not likes / highlights first.
- Country, city, age, gender as ranked percent lists / bars. Not a map.
- Bio from Instagram `biography` when present. Website when present.
- Empty / dash, never zeros.
- Kit job without a scheduler tax. No Social Set required to share `/k/`.

### Weaknesses

- No rates. Later, Beacons, and CreatorsJet put a price on the kit. Brands often want one in 30s. Randy skipped. Known hole. Keep skipped.
- Saves and shares stay off the ER numerator.
- Stories tabled.
- Instagram only. Later and MySocial already do TikTok.
- Demo sample: ≥100 followers, top-45 media.
- Interviews still unrun. Desk research only.
- Typed holes vs a typical brand kit: no contact door; no past-brand proof. Niche only if bio isn’t doing it. Testimonials later.

### Opportunities

- Live `/k/` vs a Canva PDF that rots.
- Kit without Later tax. Official Starter is $18.75/mo billed yearly ([later.com/pricing-v3](https://later.com/pricing-v3)). Share kit = current paid plans.
- Not “nobody else is free”: Beacons Free already ships a daily-updating kit at $0.
- Anti-padded kit: survive the public grid check.
- Honest Instagram Insights kit. Closest analog: OwlScran (labeled ER; missing omitted, not zeroed).

### Threats

- Later bundles kit + campaigns + scheduler in one login. Share kit = paid plans.
- Beacons Free $0 daily-updating kit.
- InfluenceFlow $0. mediakit.bio $0 / $15. CollabKit $0 / $5.
- Brands still ask for rates.
- Meta deprecations (impressions already dead).
- Stale if Insights are off.
- Connoisseur still not a kit product.

## Public kit contract

The shareable `/k/` link **is** the brand kit. Same objects the brand spends 30s on. Creator Insights is connect / last-updated / hide-when-missing — not a second page of numbers.

Hide when missing. Dash, not zero.

### On `/k/` when sourced

| Object | Notes |
| --- | --- |
| Name, username, photo | `name`, `username`, `profile_picture_url`. Hide photo if none. Cheap identity. Brands use it to know who they are looking at. |
| Followers | Always, public. |
| Engagement rate | (likes + comments) ÷ followers. Labeled. Same on Insights and `/k/`. |
| Typical reach | Insights. Hide if missing. |
| Saves | Insights. Hide if missing. |
| 30-day chart | Insights. Nivo area in WMDS. Hide if missing. |
| Six posts | Auto-selected from recent media, ranked saves → reach → likes. Empty kit if they pick from scratch is a fail. Hide when missing. No zeros. No uploaded highlights gallery in v1 — past-brands is the typed proof slot. |
| Country / city mix | Ranked percent lists or bars. Not a map. |
| Age mix | API brackets as bars. |
| Gender mix | Meta buckets only. Do not invent categories. |
| Bio | Instagram `biography` if present. |
| Website | If present. |
| Last-updated | Creator-before-share honesty. |

### Do not add

Impressions. Stories. Profile views. Bio-link clicks. Media count. Hometown. Industry. Map. Heatmap. Rates (skipped). Testimonials (later, not 30s).

Profile views, bio-link clicks, and shares are skip (Later vanity), not Weaknesses. Shares stay parked, not a fifth Stat. Sourced on `/k/` that is not a hole: name, handle, avatar, bio, website. Insights objects hide when missing.

### Creator-typed (not Graph)

Brand still needs a door and proof. Typed. Do not scrape logos. Do not invent a niche form if bio is enough.

1. **Contact (email).** Highest missing hire job. Without it the kit is a brochure.
2. **Past brands / one proof result.** What they forward internally.
3. **Niche one-liner.** Only if `biography` is not doing it. Bio first.
4. **Testimonials.** Later. Nice, not 30s.
5. **Rates.** Creators want them to filter tire-kickers; brands want a number. Randy skipped. Keep skipped.

This round’s Insights dump ([WHA-299](https://linear.app/whatmatters/issue/WHA-299/insights-static-inventory-of-locked-kit-objects)) stacks every locked object plus empty contact and past-brands slots, each with its glossary line. Ugly is fine. Not the kit look.
